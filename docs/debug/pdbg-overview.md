# PDbg 工具概述

## 工具简介

**PDbg (PowerPC Debugger)** 是一款开源的处理器调试工具，最初由 IBM/OpenPOWER 社区开发，用于通过 JTAG 接口调试 POWER 处理器。在 AST2700 环境中，PDbg 被移植用于调试 BMC 协处理器。

## 核心功能

### 1. 调试接口

- **JTAG 接口**：通过标准 JTAG 协议访问目标处理器
- **APB 访问**：通过 APB (Advanced Peripheral Bus) 访问外设和内存映射寄存器
- **FSI 接口**：支持 Floor Control System Interface (用于多芯片调试)

### 2. 调试能力

| 功能 | 描述 |
|------|------|
| 寄存器读写 | 访问 GPR、SPR、MSR 等处理器寄存器 |
| 内存访问 | 通过 APB 访问内存映射 I/O |
| 断点管理 | 设置/清除硬件断点 |
| 处理器控制 | 启动、停止、单步执行 |

### 3. 目标支持

在 AST2700 平台上，PDbg 主要用于调试：
- ARM Cortex-A 系列核心
- 系统控制处理器 (SCP)
- 电源管理处理器 (PMP)

## 与 OpenBMC 集成

在 OpenBMC 构建系统中：

1. **构建时**：通过 `pdbg_3.6.bb` 配方构建工具
2. **运行时**：在 BMC 上执行用于调试 host 处理器
3. **依赖**：需要 Device Tree Compiler (dtc) 进行设备树处理

## 安全考虑

- PDbg 访问底层硬件，需要适当的权限
- 在生产环境中应限制访问
- 主要用于开发/调试阶段
